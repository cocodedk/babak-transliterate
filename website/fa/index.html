بـ ترانسلیتریت بابک English

فارسی‌نویسی با هوش مصنوعی

ترانسلیتریت بابک یک افزونه کروم است که از هوش مصنوعی برای تبدیل متن لاتین به فارسی با کلیک‌راست استفاده می‌کند — همراه با رابط چت برای ساخت ASCII Art.

دانلود افزونه

ویژگی‌ها

  • ترانسلیتریشن لاتین به فارسی با هوش مصنوعی از طریق منوی کلیک‌راست
  • رابط چت ASCII Art با پشتیبانی هوش مصنوعی
  • ذخیره‌سازی امن کلید API با chrome.storage.sync
  • رابط کاربری تاریک با طراحی glassmorphism
  • سریع و سبک — lazy loading و debounced inputs

نصب

  1. آخرین نسخه را از GitHub Releases دانلود کنید.
  2. فایل ZIP را استخراج کنید — پوشه src/ داخل آن است.
  3. کروم را باز کنید و به chrome://extensions/ بروید.
  4. حالت توسعه‌دهنده را فعال کنید (کلید بالا-راست).
  5. روی Load unpacked کلیک کنید و پوشه src/ را انتخاب کنید.
  6. تنظیمات افزونه را باز کنید و کلید API هوش مصنوعی خود را وارد کنید.
