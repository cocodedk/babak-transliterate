بـ Babak Transliterate فارسی

AI-Powered Persian Transliteration

Babak Transliterate is a Chrome extension that uses AI to convert Latin text to Persian (Farsi) with a right-click — and generate creative ASCII art via an AI chat interface.

Download Extension

Features

  • AI-powered Latin to Persian transliteration via right-click context menu
  • ASCII Art chat interface powered by AI
  • Secure API key storage with Chrome sync storage
  • Dark mode UI with glassmorphism design
  • Fast and lightweight — lazy loading and debounced inputs

Installation

  1. Download the latest release from GitHub Releases.
  2. Extract the ZIP — you will find a src/ folder inside.
  3. Open Chrome and navigate to chrome://extensions/.
  4. Enable Developer mode (top-right toggle).
  5. Click Load unpacked and select the src/ folder.
  6. Open the extension options to set your AI API key.

Build from Source

git clone https://github.com/cocodedk/babak-transliterate.git
cd babak-transliterate
npm test   # Run tests
# Load src/ as unpacked extension in Chrome

Architecture

src/
├── manifest.json   ← Chrome MV3 manifest
├── background/     ← Service worker, AI API calls
├── content/        ← Content scripts
├── popup/          ← Toolbar popup
├── options/        ← Settings page (API key)
└── shared/         ← Transliteration engine
